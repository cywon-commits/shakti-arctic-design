## 1. 확인 1: 바닥상태에서의 가장자리 분류

### 1.1 줄기 섬 규칙
- 각 플라켓의 바깥쪽 긴 변 중점에는 수직으로 끝나는 섬이 정확히 하나 있다(이하 **줄기 섬**). 벌크에서는 이 섬 때문에 그 중점이 z=3 꼭짓점이 되고, 플라켓이 frustration을 갖는다.
- 가장자리에서 줄기 섬이 없으면 그 중점은 z=2가 된다. 플라켓은 비행복 꼭짓점 없이 닫힌 순환을 이룰 수 있다(**자유 플라켓**).

### 1.2 유효 모형
- 바닥상태 에너지 E/J = (dimer 수의 최솟값). 줄기 섬이 있는 플라켓은 반드시 짝지어지고, 줄기 섬이 없는 플라켓은 짝지어지지 않아도 된다.
- 자유 플라켓 하나당 J/2를 얻는다. 원고의 fugacity e^{J/2T}와 같은 값이며, 이제 임의의 절단에 적용된다.
- **검증:** 정수계획법(ILP)으로 구한 vertex 모형 바닥상태 에너지와 유효 모형이 44개 시료에서 모두 일치했다(불일치 0). 시료는 축 상자(오프셋 4종), 45° 마름모(오프셋 16종), 십자형, 팔각형, (2,1)·(3,1) 기울어진 정사각형, 줄기 섬을 무작위로 절반만 남긴 가장자리 8종이다.
- 유효 모형이 해를 못 주는 경우(줄기 섬이 모두 있는데 타일링이 불가능한 시료 12개)에는 ILP 에너지가 더 높다. 잘린 플라켓의 남은 섬과 짝을 이루는 것으로 보이며, 이 영역은 아직 모형화하지 않았다.

### 1.3 두 가지 마감과 결과
- **술 달린 마감(fringed):** 잘린 플라켓의 섬을 남긴다. 줄기 섬이 보존되어 자유 플라켓이 없다. 1단계 사전의 dimer 분류가 그대로 바닥상태다.
- **깨끗한 마감(clean):** 온전한 플라켓의 둘레 섬만 남긴다. 자유 플라켓이 생기고, 바닥상태는 자유 플라켓 수를 최대로 한다.

| 절단 | 술 달린 마감 | 깨끗한 마감 |
|---|---|---|
| 축, 블록 경계 | Aztec (면 극한) | Aztec (면 극한). 두 마감이 같다 |
| 축, 블록 관통 | Aztec (면 극한) | **평평, 전부 액체** (칸당 엔트로피 0.233 → 0.255, 벌크값으로 증가) |
| 45°, 짝수 오프셋 | 바닥상태 유일 (꼭짓점 극한) | **액체** (칸당 0.263 → 0.275) |
| 45°, 홀수 오프셋 | 타일링 불가, 추가 비행복 꼭짓점 | 액체 |

- 깨끗한 마감의 값은 자유 플라켓 집합이 유일한 크기에서 Kasteleyn으로 센 것이다. 블록 관통 축 상자는 변 길이에 따라 자유 집합이 유일하지 않은 경우가 있다(변 16, 24).
- 1단계의 식 D2로 이해된다. 블록 관통 축 절단은 기하학적 기울기가 극한(1)인데, 자유 플라켓이 밀도 1/4로 생겨 4 × 1/4만큼 상쇄해 0이 된다. 블록 경계 절단은 반대로 0에서 1이 된다.

### 1.4 1단계 문서에 대한 정정
- "45° 짝수 절단 정사각형은 바닥상태가 유일하다"는 **술 달린 마감에서만** 맞다. 깨끗한 마감에서는 자유 플라켓이 생겨 액체가 된다(D=12에서 E = 50J 대 60J).
- "가장자리 층 전체를 비우면 Aztec이 남는다"는 맞지만, 실제 바닥상태에서 자유가 되는 것은 층 전체가 아니라 가장자리에 붙은 평행 플라켓 2(n+1)개뿐이다(원고와 같다).

### 1.5 vorticity 원고에 대한 주의
원고의 "블록을 관통해 자른 배열에는 이 메커니즘이 없다"는 문장은 잘린 플라켓의 섬을 가장자리에 남긴다는 전제에서 맞다(원고도 그렇게 적고 있다). 잘린 플라켓의 섬을 지우면 결론이 반대가 된다. 변 8에서 E = 10J(깨끗) 대 12J(술)이고, 시료는 Aztec이 아니라 액체가 된다. 원고에 마감 조건을 한 문장으로 명시해 두는 편이 안전하다.

### 1.6 설계 어휘 (확정)
| 가장자리 종류 | 구현 | 온도 의존 |
|---|---|---|
| F (면 극한, 접점 하나) | 축 블록 경계 / 축 블록 관통 + 술 | 블록 경계는 T_on 아래에서만. 술은 기하학적 |
| P (꼭짓점 극한, 얼음상 하나) | 45° 짝수 + 술 | 기하학적 |
| 평평 (액체가 닿음) | 축 블록 관통 + 깨끗 / 45° + 깨끗 | 자유 플라켓 에너지 J/2로 유지 |
| 프로그램 가능 | 깨끗한 가장자리에서 줄기 섬을 골라 남김 | 줄기 섬 하나가 높이 계단 4를 켜고 끈다 |

## 2. 확인 2a: 팔각형 = 옮길 수 있는 arctic 원 (정확)

시료: 축 변 |X| ≤ n, |Y| ≤ n (블록 관통, 술)과 45° 변 X+Y ≤ d_NE, −X+Y ≤ d_NW, −X−Y ≤ d_SW, X−Y ≤ d_SE (짝수 오프셋, 술).

- **타일링 가능 조건:** d_NE + d_SW = d_NW + d_SE.
- **결과:** 강제되는 도미노를 차례로 벗겨내면, 남는 영역은 정확히 축 정사각형

  X ∈ [n − d_SW, d_NE − n],  Y ∈ [n − d_SE, d_NW − n]

  이고 이것은 Aztec diamond다. 나머지는 유한 크기에서도 완전히 얼어 있다.
- 따라서 액체 영역은 이 정사각형에 내접하는 원이다. 중심은 ((d_NE − d_SW)/2, (d_NW − d_SE)/2), 반지름은 (d_NE + d_SW)/2 − n이다.
- **검증:** n = 21인 균형 팔각형 80여 개에서 벗겨낸 영역이 축 정사각형과 칸 단위로 같았고, 타일링 수가 2의 정수 거듭제곱(10, 21, 36, …, 171 ln 2)으로 Aztec 값과 정확히 일치했다.
- 의미: 45° 변 네 개의 위치만으로 arctic 원의 **위치와 크기를 독립적으로** 정한다. 근사가 아니라 조합론적 항등식이므로 작은 실험 시료에서도 성립한다. d = n이면 액체가 사라지고 바닥상태가 유일해진다.

## 3. 확인 2b: 십자형 시료의 세 영역

시료: 팔 끝까지 n, 팔 반폭 c인 십자형. 모든 변이 축 방향 F형(블록 관통, 술)이다.

| 범위 | 액체 영역 | 근거 |
|---|---|---|
| c < n/3 | 타일링 불가 | 팔 양옆의 높이 차가 팔을 따라 선형으로 벌어져 Lipschitz 한계 2c를 넘는다. n = 25에서 c = 7은 불가, c = 9는 가능. n = 37에서 c = 11은 불가, c = 13은 가능 |
| n/3 < c < n/√2 | **class 10 곡선** (4절) | 오목 모서리마다 얼음상 셋이 만나는 작은 얼음 주머니가 생긴다 |
| c ≥ n/√2 | 반지름 n인 원 (전체 정사각형의 arctic 원) | 오목 모서리가 원 밖 얼음 속에 있다. n = 25에서 ln Z = 299.98, 299.9998, 300.0000 ln 2 (c = 19, 21, 23) |

- c = n/3에서는 곡선이 반지름 n/3인 원 다섯 개(중심 하나, 팔 넷)가 서로 접하는 모양으로 퇴화한다. 팔의 목이 얼어 액체가 끊어지는 점이다.
- 설계 규칙: 팔 길이(n − c)는 팔 폭(2c)을 넘을 수 없다.

## 4. 십자형의 arctic 곡선 (닫힌 식)

### 4.1 구조
균일 도미노의 스펙트럼 곡선은 유리곡선이고, 얼음 경계는 접선족의 포락선이다. 한 방향 접선은 법선각 ν와 원점에서의 거리 H로 쓴다.

  X cos ν + Y sin ν = H

- **Aztec:** ν = θ, H = n. 원이다.
- **십자형:** 90° 회전이 높이 부호를 바꾸므로(H ↔ V), 대칭과 양립하는 Blaschke 곱의 차수는 1, 5, 9, …뿐이다. 변 12개와 오목 모서리의 숨은 접선 8개(이웃 팔 옆변의 연장선)를 합친 20개가 차수 5를 요구한다.

  ν(θ) = 5θ + 2 atan2(p sin 4θ, 1 − p cos 4θ)
  H(θ) = (a₀ + a₄ cos 4θ) / (1 + p² − 2p cos 4θ)

- 곡선 위의 점은 (X, Y) = H (cos ν, sin ν) + (H′/ν′)(−sin ν, cos ν)이다.

### 4.2 매개변수를 정하는 조건 (3개)
| 조건 | 의미 |
|---|---|
| ν = 0에서 H = n | 팔 끝 변에 접한다 |
| ν = π/2에서 H = c | 팔 옆변에 접한다 |
| ν = π에서 H = −c | 이웃 팔 옆변의 연장선에 접한다 (오목 모서리 얼음 주머니의 경계) |

- 풀이 범위: p는 c/n = 1/3에서 +1, c/n = 1/√2에서 −1로 간다(수치로 0.335와 0.707에서 해가 끝남). 3절의 두 문턱과 일치한다.
- 예 (n = 1): c = 0.40이면 p = 0.2986, a₀ = −0.1839, a₄ = 0.6759. c = 0.50이면 p = −0.2660, a₀ = 0.6155, a₄ = 0.9872. c = 0.60이면 p = −0.6639, a₀ = 1.3366, a₄ = 1.4320.
- p(c/n)의 명시적 식은 아직 구하지 않았다. 지금은 대수 방정식 세 개를 수치로 푼다.

### 4.3 유한 크기 검증
Kasteleyn 역행렬로 각 칸의 최대 dimer 확률 P_max를 정확히 구하고, 곡선에 대한 감김수로 예측한 액체/얼음과 비교했다(얼음 기준 P_max > 0.9).

| 시료 | 칸 수 | 곡선에서 2 이상 떨어진 칸의 오분류 | 4 이상 | 6 이상 |
|---|---|---|---|---|
| n = 61, c = 21 | 4120 | 0 | 0 | 0 |
| n = 61, c = 31 | 5520 | 0 | 0 | 0 |
| n = 61, c = 41 | 6520 | 0 | 0 | 0 |
| n = 121, c = 45 | 17488 | 63 | 4 | 0 |
| n = 121, c = 61 | 21840 | 98 | 6 | 0 |

- 오분류는 모두 곡선 바로 옆 칸이다. 전체 오분류는 2.4–3.5%이다.
- n = 61, c = 21에서는 오목 모서리의 세 얼음상(도미노 종류 셋)이 곡선의 주머니 안에 정확히 들어온다.
- 그림: `figs/plus_verify_n121.png`, `figs/overlay_n61.png`.

### 4.4 한계
- 4.1의 접선족 형태는 Kenyon–Okounkov의 c = 0 해 구조와 Astala 등의 결과를 도미노에 적용해 **가정한** 것이다. 유도 과정을 증명 수준으로 쓰지는 않았다.
- "숨은 접선이 이웃 변의 연장선"이라는 조건은 수치 그림에서 읽어 내 세운 것이고, 결과가 수치와 맞는다는 것으로만 뒷받침된다.
- 이 곡선이 문헌에 이미 있는지는 확인하지 않았다. 도미노의 비볼록 다각형 영역에 대한 선행 결과를 따로 검색해야 한다.

## 5. 논문으로 갈 때의 구성 제안
1. 줄기 섬 규칙과 유효 경계 단량체 모형 (1절). 물리적 핵심이고 실험 설계 규칙이다.
2. 팔각형: 옮길 수 있는 arctic 원 (2절). 정확하고 작은 시료에서도 성립한다.
3. 십자형: 원이 아닌 액체 영역과 두 문턱 n/3, n/√2 (3·4절).
4. 온도 전환: 블록 경계 변(T_on)과 줄기 섬 프로그래밍.

## 1. 상자 규칙 (극한 쌍 원리)

Shakti 좌표에서 기울기 영역이 [−1, 1]²이므로, 모든 타일링의 높이는 다음을 만족한다.

  |h(q) − h(p)| ≤ |X_q − X_p| + |Y_q − Y_p| ≡ ‖q − p‖₁

**규칙.** 경계의 두 점 A, B에서 h(B) − h(A) = ‖B − A‖₁이면, A와 B를 대각 꼭짓점으로 하는 축 평행 상자 안의 모든 점 q에서 h(q) = h(A) + ‖q − A‖₁로 고정된다. 상자는 꼭짓점 얼음상 하나로 언다.

**증명.** 상자 안의 q에서는 ‖B − q‖₁ + ‖q − A‖₁ = ‖B − A‖₁이다. 따라서 h(B) − h(A) = [h(B) − h(q)] + [h(q) − h(A)] ≤ ‖B − q‖₁ + ‖q − A‖₁ = ‖B − A‖₁에서 등호가 성립해야 하고, 두 항이 각각 최댓값이다. ∎

- 격자에서는 ℓ1 거리를 격자 위의 방향 있는 거리로 바꾸면 같은 논증이 유한 크기에서 정확히 성립한다. 그래서 얼어붙는 영역이 칸 단위로 맞는다.
- 같은 부등식이 **타일링 가능 조건**이다. 경계 높이가 어떤 두 경계점에서 부등식을 어기면 타일링이 없다.

### 1.1 따름정리: 팔각형
직사각형 |X| ≤ a, |Y| ≤ b를 짝수 45° 변 넷으로 자른 시료를 보자. 오른쪽 변의 점 P와 NE 변의 위쪽 끝 A는 경계를 따라 잰 높이 차가 ℓ1 거리와 같다(축 변은 단위 길이당 1, 45° 변은 단위 격자 벡터당 2). 상자 규칙에 의해 띠 전체가 언다. 네 변에서 같은 일이 일어나 얼음 띠 넷이 바람개비 모양으로 안쪽 직사각형을 둘러싼다.

45° 변은 이웃한 두 축 변 가운데 **하나**의 높이 변화를 이어받고, 그 변을 따라 얼음 띠를 만든다. 어느 쪽인지는 그 변의 오프셋 종류가 정한다(변을 반시계 순서로 셀 때).

| 오프셋 종류 | 이어받는 변 | NE | NW | SW | SE |
|---|---|---|---|---|---|
| d ≡ 2 (mod 4) | 바로 앞의 변 | 오른쪽 | 위 | 왼쪽 | 아래 |
| d ≡ 0 (mod 4) | 바로 뒤의 변 | 위 | 왼쪽 | 아래 | 오른쪽 |

**일반 규칙.** 모서리마다 절단이 있거나 없고, 종류가 제각각이어도 다음이 성립한다.

1. 한 축 변을 두 절단이 함께 이어받으면 타일링이 없다. 두 절단의 먼 끝점 사이에서 높이 차가 ℓ1 거리를 넘기 때문이다.
2. 그렇지 않으면 각 절단이 자기가 이어받은 변을 안쪽으로 민다. NE 절단은 오른쪽 변을 X = d_NE − b로(종류 2) 또는 윗변을 Y = d_NE − a로(종류 0) 옮긴다. 나머지 모서리도 회전해서 같다.
3. 남는 직사각형이 정사각형일 때만 타일링이 있고, 남는 영역은 그 정사각형의 Aztec diamond다.

따름 결과:

- 네 절단이 모두 같은 종류이면 바람개비가 된다. 종류 2는 X ∈ [b − d_SW, d_NE − b], Y ∈ [a − d_SE, d_NW − a]이고, 종류 0은 X ∈ [b − d_NW, d_SE − b], Y ∈ [a − d_SW, d_NE − a]로 반대로 감긴다.
- **네 모서리를 모두 자르면서 종류를 섞으면 타일링이 없다.** 한 변도 겹치지 않으려면 네 절단이 모두 앞의 변을 고르거나 모두 뒤의 변을 골라야 하기 때문이다.
- 절단이 셋 이하이면 종류를 섞을 수 있다. 예를 들어 폭이 넓은 직사각형(a > b)의 위쪽 두 모서리를 서로 다른 종류로 자르면 좌우 변이 안으로 밀려 변 2b인 정사각형이 남는다.
- **이 족에서는 액체 영역이 언제나 원이다.** 볼록한 모서리 절단만으로는 원을 옮기고 줄일 수 있을 뿐, 모양을 바꾸지 못한다. 원이 아닌 모양에는 오목 모서리가 필요하다(3절).

검증(`mixed_octagon.py`): (a, b) = (13, 13), (17, 13), (13, 9), (17, 9)에서 절단 위치와 종류의 모든 조합 8500개(유효한 팔각형)를 예측과 비교했다. 타일링이 있는 211개는 남는 영역이 칸 단위로 일치했고, 없는 8289개도 모두 맞았다. 불일치는 0이다. 종류가 섞인 시료 6692개 중 타일링이 있는 것은 44개이고 모두 절단이 셋 이하다. 두 절단이 서로 교차하는 1104개는 팔각형이 아니므로 규칙 밖에 두었다.

- **정정:** `arctic-checks.md` 2절의 식은 d ≡ 2 (mod 4)에만 맞다. 거기서 시험한 시료가 모두 그 종류였다.
- 정사각형 조건은 같은 종류의 네 절단에서 d_NE + d_SW − 2b = d_NW + d_SE − 2a이다.

### 1.2 따름정리: 십자형의 c ≥ n/3
팔의 윗변과 아랫변은 ∂_X h가 +1과 −1이다. 팔 끝에서 두 변의 높이 차는 2c(최대)이고, 안쪽으로 가면서 선형으로 줄어 X에서 2(c − n + X)가 된다. 팔의 뿌리 X = c에서 이 값이 −2c보다 작아질 수 없으므로 2c − n ≥ −c, 즉 c ≥ n/3이다. c = n/3에서는 뿌리의 두 오목 모서리가 극한 쌍이 되어 목이 언다.

### 1.3 c ≥ n/√2 [논증]
전체 정사각형의 Aztec 해에서 모서리 얼음 영역은 원 X² + Y² = n² 바깥이다. 잘라낸 모서리 정사각형 [c, n]²이 모두 원 밖에 있으려면 가장 가까운 점 (c, c)가 원 밖이면 되고, 이것이 c ≥ n/√2이다. 이때 Aztec 해를 십자형에 제한한 것은 십자형의 경계 조건을 그대로 만족한다(새 변 X = c, Y = c 위에서 얼음상의 접선 기울기가 F형 변의 값과 같다). 최소화 해의 유일성을 쓰면 십자형의 해는 이 제한이다. 수치로는 n = 25에서 ln Z가 300 ln 2로 지수적으로 수렴한다.

## 2. 접선족의 유도

### 2.1 특성선 해 [증명, Kenyon–Okounkov 전제]
액체 영역에서 복소 기울기 (z, w)는 스펙트럼 곡선 P(z, w) = 0 위에 있고, 부피 제약이 없을 때 복소 Burgers 방정식 z_x/z + w_y/w = 0을 만족한다. w = w(z)를 넣으면

  z_x + (z w′/w) z_y = 0

이므로 z는 직선 dy/dx = z w′/w 위에서 일정하다. w′ = −P_z/P_w를 쓰면 일반해는 임의의 해석함수 Q에 대해

  x · z P_z + y · w P_w = Q(z)

이다. 실수 z에서는 이것이 실직선이고, 그 포락선이 얼음 경계다.

### 2.2 균일 도미노
P = 1 + z + w − zw로 잡으면 w = (1 + z)/(z − 1)이고, 직선은 2z x + (z² − 1) y = −(z − 1)Q(z)가 된다. z = tan(φ/2)로 두면

  x sin φ − y cos φ = H,  H = −(z − 1)Q / (1 + z²)

즉 법선각 ν = φ − π/2인 직선이다. z ∈ {0, 1, ∞, −1}이 축 방향 접선 넷(Newton 정사각형의 네 면)에 해당한다. Aztec diamond는 H = n(상수)이고 원이 나온다.

### 2.3 다각형 시료
액체 영역을 원판으로 균일화하면(좌표 u, 경계 u = e^{iθ}) z는 차수 d의 Blaschke 곱 B(u)이고, H는 경계에서 유계이므로

  H(θ) = T(θ)/|B의 분모|²,  T는 차수 ≤ d인 실 삼각다항식

꼴이다. 축 방향 접선은 모두 4d개이고, B가 단조이므로 네 면의 표지가 경계를 따라 순환 순서로 나타난다.

### 2.4 차수 제한 [증명, 같은 전제]
블록 모서리 중심의 90° 회전 R은 H ↔ V를 바꾸므로 h → −h이고, 기울기는 s → −R s로 변한다. 네 면에 대한 작용은 한 칸 순환이다. 시료가 R에 대해 대칭이면 균일화 좌표에서 R은 u → iu이고, ζ = (z − i)/(z + i)에 대해

  B(iu) = i B(u)

가 성립한다. 따라서 B의 영점 집합은 i배에 대해 불변이고 B(u)/u는 u⁴의 함수다. 차수는 d = 1 + 4k이다. d = 1이 Aztec이고, 변이 12개인 십자형은 4d ≥ 12에서 d = 5다.

  B(u) = u (u⁴ − p)/(1 − p u⁴),  T(θ) = a₀ + a₄ cos 4θ  (거울 대칭에서 p는 실수)

### 2.5 숨은 접선 [논증]
d = 5이면 축 방향 접선이 20개인데 변은 12개다. 볼록 모서리에서는 표지가 한 칸 나아가지만 오목 모서리에서는 세 칸 나아가야 하므로(B가 단조), 오목 모서리마다 변이 아닌 접선이 둘씩 있다.

- 팔 윗변(∂_X h = +1 고정)의 접점을 지나면 변에는 얼음상 (+1, −1)이 붙고, 이웃 팔 옆변에는 (−1, +1)이 붙는다. 두 상은 Newton 정사각형의 맞은편 꼭짓점이라 직접 맞닿을 수 없고, 사이에 (−1, −1) 상이 낀다.
- 이웃한 두 얼음상의 경계는 기울기 차에 수직인 직선이다. (+1, −1)과 (−1, −1) 사이는 X = c + δ, (−1, −1)과 (−1, +1) 사이는 Y = c + δ이고 δ는 같다.
- δ > 0이면 (−1, −1) 상이 변에 닿아 경계 조건과 모순이다. δ < 0이면 맞은편 꼭짓점의 두 상이 대각선에서 맞닿는데, 이런 꺾임은 최소화 해가 될 수 없다. 따라서 δ = 0이다.
- 액체 경계는 얼음–얼음 경계선과 만나는 점에서 그 선에 접한다. 그러므로 숨은 접선은 이웃 팔 옆변의 연장선 X = c, Y = c다.

빈틈: δ < 0의 배제와 "만나는 점에서 접한다"는 엄밀하게 보이지 않았다. n = 61, c = 21의 정확 계산에서 세 얼음상의 배치가 이 그림과 일치한다.

### 2.6 숨은 접선 조건의 독립 검증: L자 시료 [수치확인, 2026-11-25]
오목 모서리가 하나인 시료(정사각형 |X|, |Y| ≤ n에서 X > a, Y > b를 떼어낸 L자)에는 선행 결과가 있다. Colomo–Pronko–Sportiello(arXiv:1807.07549)가 전혀 다른 방법(6-vertex 모형의 Tangent method, 경로 하나의 궤적)으로 구한 식 (4.15)–(4.17)이다. 같은 시료에 2.3–2.5절의 규칙을 그대로 적용해 비교했다(`lshape_theory.py`, `lshape_cps.py`, `lshape_compare.py`).

- 축 방향 접선은 변 6개와 숨은 접선 2개로 모두 8개이므로 d = 2다. B(u) = e^{iγ} u (u − q)/(1 − q̄u), H = T(θ)/|1 − q̄u|², T는 차수 2의 삼각다항식이다.
- 미지수는 7개(q의 실수부·허수부, T의 계수 5개), 조건은 8개다. ν = 0, π/2, …, 7π/2에서 H = n, b, −a, −b, a, n, n, n. 경계 높이가 닫히므로 조건 하나는 자동으로 성립하고, 실제로 잔차 10⁻⁹의 해가 있다.
- a = b = 0.4n과 0.6n에서 두 곡선은 전 구간(첨점 두 개 포함)에서 일치한다. 차이의 최댓값은 10⁻⁴ n 수준이고 이는 비교한 점의 간격이다(`figs/lshape_vs_cps.png`).
- 좌표 대응: 6-vertex 정사각형 [0, 1]²의 (x, y) = ((1 + X/n)/2, (1 − Y/n)/2), R = (n + a)/(n − a), α = 1/2.

뜻: "숨은 접선은 이웃 변의 연장선이고 그 높이는 −a, −b다"라는 2.5절의 조건이 독립적으로 유도된 결과를 재현한다. 십자형은 같은 조건을 네 모서리에 동시에 쓴 것이므로 3절의 식도 같은 근거 위에 선다. 남는 빈틈은 조건의 엄밀한 증명이고, 네 모서리가 서로 영향을 주는 경우의 타당성은 4절의 수치 검증이 맡는다.
- 첨점은 숨은 접선 위에 있다. 첨점에서 곡선은 연장선 X = a, Y = b에 접한다.
- a ≥ n/√2에서는 q가 단위원으로 가고(a = 0.7n에서 |q| = 0.995) 곡선이 원으로 돌아간다.

## 3. 십자형 곡선의 명시적 식

조건 셋(ν = 0에서 H = n, ν = π/2에서 H = c, ν = π에서 H = −c)을 닫힌 꼴로 푼다.

- B = −1인 점: u⁵ − p u⁴ − p u + 1 = 0은 회문 다항식이다. u = −1을 인수로 빼면 2 cos θ₂ = [(1 + p) + √((1 − p)² + 4)]/2.
- B = i인 점: 회전 대칭으로 B = 1의 방정식으로 옮기면 2 sin θ₁ = [√((1 − p)² + 4) − (1 + p)]/2.
- σ ≡ 2 sin θ₁, κ ≡ 2 cos θ₂라 하면 σκ = 1 − p, κ − σ = 1 + p이고, κ = (2 + σ)/(1 + σ)이다.

그러면 모든 것이 σ ∈ (0, √2)의 유리식이다 (ρ ≡ c/n).

  ρ = (σ² + 2σ + 2)/(6 + 4σ − σ²)
  σ = [2ρ − 1 + √(10ρ² − 1)]/(1 + ρ)
  p = (1 − σ − σ²)/(1 + σ)
  a₄/n = 2(σ⁴ + 3σ³ + 3σ² + 2σ + 2) / [(1 + σ)(6 + 4σ − σ²)]
  a₀/n = −(σ⁶ + 2σ⁵ − 10σ⁴ − 28σ³ − 14σ² + 8σ + 4) / [(1 + σ)²(6 + 4σ − σ²)]

- σ → 0에서 ρ = 1/3, p = 1. σ = √2에서 ρ = 1/√2, p = −1. 1절의 두 문턱이 식에서 그대로 나온다.
- 근호 안의 10ρ² − 1은 ρ > 1/√10에서 양수이므로 전 구간에서 실수다.
- 수치 풀이와 소수 6자리까지 일치한다(`derive_closed_form.py`).
- 곡선의 점: (X, Y) = H (cos ν, sin ν) + (H′/ν′)(−sin ν, cos ν), ν = 5θ + 2 arctan[p sin 4θ/(1 − p cos 4θ)].

## 4. 3단계: 큰 크기에서의 검증

### 4.1 역행렬의 정밀도 문제
각 칸의 짝지음 확률의 합은 1이어야 한다. 이 합의 오차로 보면 배정밀도 Kasteleyn 역행렬은 n ≈ 61까지만 믿을 수 있다(`precision_check.py`).

| 시료 | 조건수 | 최대 \|ΣP − 1\| |
|---|---|---|
| n = 31, c = 15 | 3 × 10⁵ | 5 × 10⁻¹⁴ |
| n = 61, c = 31 | 5 × 10¹² | 5 × 10⁻⁶ |
| n = 91, c = 45 | 2 × 10¹⁸ | 0.43 |
| n = 121, c = 61 | 2 × 10²⁴ | 2.7 |

처음 만든 n = 121 검증과 그림은 칸의 9%가 오염되어 있었다.

### 4.2 해결: urban renewal 점화식 (`shuffle_probs.py`, `plus_shuffle.py`)
가중 Aztec diamond의 변 확률은 Propp의 일반화된 domino shuffling 점화식으로 정확히 계산된다. 모든 단계가 양수의 덧셈과 곱셈이라 상쇄가 없고, 로그 영역에서 계산하면 어떤 크기에서도 배정밀도로 충분하다.

- **십자형을 넣는 방법:** 십자형은 전체 정사각형(Aztec diamond)의 부분이다. 십자형 밖의 칸들을 고정된 완전 매칭 하나로 덮고, 그 칸에 닿는 다른 변의 가중치를 0(로그 가중치 −600)으로 둔다. 그러면 큰 Aztec의 타일링이 십자형의 타일링과 일대일로 대응한다.
- **검증:** 무작위 가중치의 Aztec(차수 2–8)에서 Kasteleyn 값과 10⁻¹⁵ 안에서 같다. 십자형 n = 15, 31, 41에서 역행렬 결과와 10⁻¹⁴ – 10⁻¹¹ 안에서 같다.
- **비용:** O(n³). n = 241은 25초, n = 481(칸 35만 개)은 85초다. 확률 합의 오차는 모든 크기에서 10⁻¹⁴ 이하다.

### 4.3 곡선의 검증 (`verify_shuffle.py`)
얼음의 기준은 1 − P_max < 0.1이고, 곡선에 대한 감김수로 예측한 것과 칸마다 비교했다.

| 시료 | 칸 수 | 곡선에서 이 거리 넘게 떨어진 칸의 오분류가 0 | 전체 오분류 |
|---|---|---|---|
| n = 61, c = 31 | 5520 | 2칸 | 2.7% |
| n = 121, c = 61 | 21840 | 2칸 | 1.8% |
| n = 241, c = 83 (c/n = 0.34) | 65752 | 3칸 | 1.9% |
| n = 241, c = 121 (0.50) | 86880 | 3칸 | 1.4% |
| n = 241, c = 145 (0.60) | 97248 | 4칸 | 1.3% |

- 오분류는 모두 곡선에 붙은 띠 안에 있고, 띠의 폭은 n의 1 – 2%다. 전체 오분류 비율은 n이 커질수록 줄어든다.
- c/n = 0.34에서는 오목 모서리의 얼음 주머니가 곡선의 고리 안에 들어온다(`figs/plus_verify_n241.png`의 확대 그림).
- 앞서 n = 121에서 보였던 "2 – 6칸 거리의 오분류"는 정밀도 오류였다. 지금은 2칸 밖에서 0이다.

### 4.4 경계 요동의 눈금잡기 (`width_scaling.py`)
곡선 바깥에서 액체의 정도는 exp[−(4/3)(d/w)^{3/2}]로 줄어든다(Airy 꼬리). (−ln(1 − P_max))^{2/3}을 거리 d에 대해 직선으로 맞춰 w를 구했다. 오목 모서리 근처는 제외했다.

| n | 61 | 121 | 241 | 481 |
|---|---|---|---|---|
| w | 2.43 | 3.03 | 3.92 | 5.04 |
| w / n^{1/3} | 0.617 | 0.613 | 0.630 | 0.643 |

- 맞춘 지수는 0.355(네 크기), 0.368(큰 세 크기)이다. 기대값 1/3과 가깝지만 약간 크다.
- w/n^{1/3}이 4% 정도 천천히 올라간다. 호마다 곡률이 다른 것을 한데 섞어 맞춘 탓일 수 있다. 호 하나를 골라 다시 재는 것이 남은 일이다.

### 4.5 남은 3단계 계산
1. 요동 폭을 호 하나에서 재기(곡률과 w의 관계 포함).
2. 두 절단이 교차하는 시료(육각형·오각형으로 퇴화)의 규칙.
3. 타일링이 불가능한 시료(c < n/3, 불균형 팔각형)의 열린 꼭짓점 바닥상태.
4. 깨끗한 마감에서 자유 집합이 유일하지 않을 때의 Pfaffian.
5. 온도 스위치 시료.

## 5. 유한 온도: 경계 단량체 모형의 정확한 계산 (2026-11-25, 온도 스위치 시료의 준비)

### 5.1 모형과 눈금 [유도]
- 줄기 섬 규칙에 따라 유한 온도의 유효 모형은 "자유화 가능한 가장자리 플라켓이 가중치 y = e^{J/2T}로 짝 없이 남을 수 있는 dimer 모형"이다.
- 자유 플라켓 수는 변 길이 n에 비례하고 엔트로피 변화는 n²에 비례하므로 전환은 T ~ J/n에서 일어난다. 이 온도에서 벌크 들뜸의 가중치는 e^{−J/T} ~ e^{−n}이라 무시된다. 눈금 분리는 n이 클수록 정확해진다.
- 한 변의 자유 플라켓은 모두 같은 종류(H 또는 V)이고 하나가 높이 계단 4를 준다(D2). 따라서 변의 에너지는 −(J/8) × (그 변 양 끝의 높이 차)로, 변을 따른 전미분이다. 경계 에너지는 모서리 높이에만 의존하고 변 안쪽의 높이 분포는 엔트로피가 정한다(자연 경계 조건).

### 5.2 Pfaffian 식 (`bmono.py`) [수치확인]
단량체가 바깥 면에만 있으면 모형은 Pfaffian으로 풀린다(Giuliani–Jauslin–Lieb 2016).

  Z(y) = Pf(K + M),  M_ij = G_i G_j y²  (i < j, 자유화 가능한 칸을 경계를 따라 순서대로 번호 붙임)

- G_i는 0번 칸에서 i번 칸까지 경계 경로를 따른 Kasteleyn 부호의 곱이다. G_i G_j는 시료 바깥에 그린 가상의 변 (i, j)의 Kasteleyn 부호와 같다.
- 전수 계산과의 비교: 블록 경계 정사각형(32칸), 블록 관통 정사각형·깨끗한 마감(24칸), 45° 마름모(8칸), 십자형(40칸)에서 ln Z가 y = 0.3, 1, 2.5에서 10⁻¹⁰ 이내로 일치한다. 십자형은 오목한 시료다.
- 자유 집합이 유일하지 않은 시료의 바닥상태 수도 이 식의 y → ∞ 극한으로 얻는다(4.5절의 남은 항목 하나가 풀린다).
- 한계: 밀집 역행렬을 쓰므로 수천 칸까지다. 4.1절의 정밀도 문제는 큰 y(얼음 영역이 넓을 때)에서 다시 나타날 수 있고, 아직 점검하지 않았다.

### 5.3 블록 경계 정사각형 (`switch_square.py`) [수치확인]
x ≡ T_on/T, T_on = J/[(n + 2) ln 2] (vorticity 원고의 식), n은 T = 0에서 남는 Aztec diamond의 차수.

| 변 | n | x = 0.25 | 0.5 | 0.75 | 1.0 | 1.25 | 1.5 |
|---|---|---|---|---|---|---|---|
| 16 | 6 | 0.512 | 0.676 | 0.815 | 0.917 | 0.973 | 0.993 |
| 24 | 10 | 0.492 | 0.689 | 0.840 | 0.945 | 0.990 | 0.999 |
| 40 | 18 | 0.479 | 0.703 | 0.864 | 0.968 | 0.999 | 1.000 |
| 56 | 26 | 0.475 | 0.709 | 0.874 | 0.978 | 1.000 | 1.000 |

(값: 자유화 가능한 플라켓 가운데 자유인 것의 평균 비율)

- x > 1에서 비율이 1로 붙고 크기가 클수록 날카로워진다. 원고의 T_on을 독립적으로 재현한다.
- x < 1에서는 크기에 거의 의존하지 않는 눈금 함수로 수렴한다. 5.1절의 그림(모서리 높이가 장에 비례해 자라다가 x = 1에서 포화)과 맞는다.
- 이 시료의 x < 1 영역은 Aztec diamond 가장자리의 빈칸 모형, 즉 "Thermal vacancies melt arctic order"의 경계 모형과 같은 문제다. 정량적 대응(z와 y, 가장자리 층끼리 짝짓는 경우)은 맞춰 보지 않았다.

### 5.4 직사각형의 분류 (`mixed_scan.py`, `mixed_digest.py`) [수치확인]
네 변의 오프셋(mod 4)을 모두 바꾼 256개 직사각형(변 16–19, 술 마감)을 정확히 계산했다. 짝수 오프셋은 블록 경계 변(E, 자유화 가능한 플라켓이 있음), 홀수 오프셋은 블록 관통 변(O, 술 때문에 없음)이다. 대칭으로 묶으면 여섯 종류다.

| 변의 조합 | 시료 수 | 유효 모형에 상태 없음 | T = 0에서 완전히 얾 | 액체 비율, T = 0 → y = 1 |
|---|---|---|---|---|
| E 넷 | 16 | 0 | 0 | 0.69–0.81 → 1.00 (원 → 전체 액체) |
| E 셋, O 하나 | 64 | 16 | 32 | 온도에 따라 변하지 않음 (0 또는 0.86–0.88) |
| O 둘이 마주 봄 | 32 | 32 | – | – |
| **O 둘이 이웃함** | 64 | 0 | **64** | **0 → 0.66–0.83** |
| O 셋 | 64 | 64 | – | – |
| O 넷 | 16 | 8 | 0 | 0.79–0.83, 온도 무관 (Aztec) |

- "상태 없음"은 타일링이 불가능해 비행복 꼭짓점이 더 필요한 경우다(유효 모형의 범위 밖).
- 5.3절 뒤에 적었던 "마주 보는 두 변만 블록 경계"인 시료는 모두 여기에 든다. 단순한 스위치 그림은 성립하지 않는다.
- E 셋·O 하나에서는 H와 V의 수가 달라 자유 플라켓 수가 색 불균형으로 고정되는 경우가 많다(64개 중 40개). 그러면 온도 의존이 없다.
- **이웃한 두 변이 블록 경계, 나머지 두 변이 블록 관통인 시료가 스위치다.** 64개 오프셋 조합 모두에서 T = 0의 바닥상태가 유일하고(자유화 가능한 플라켓이 모두 자유), 높은 온도에서는 액체다.
- 정밀도: 얼어붙은 시료에서는 배정밀도 역행렬이 300칸에서도 무너진다(자유 플라켓 수가 4.55로 나오는 등). 그래서 `bmono.py`의 `exact`는 정수 y에서 유리수 연산(python-flint)을 쓴다. 칸 수가 홀수인 시료는 항상 단량체인 보조 칸 하나를 더해 처리했고, 전수 계산과 12개 시료에서 일치한다. 경계 순서는 바깥 면을 따라 걷는 방식으로 정한다(각도 정렬은 깨끗한 마감의 9 × 9 시료에서 틀렸다).

### 5.5 모서리 스위치 시료 (`switch_corner.py`, `figs/switch_corner.png`) [수치확인]
시료: X, Y ∈ [0, L + 1], 술 마감. 서쪽·남쪽 변이 블록 경계(자유화 가능한 플라켓 m = L/2개), 동쪽·북쪽 변이 블록 관통이다.

| (J/2T)/m | 자유 비율 L = 16 | 24 | 32 | 액체 비율 L = 32 |
|---|---|---|---|---|
| 0 | 0.148 | 0.113 | 0.092 | 0.750 |
| 0.173 | 0.355 | 0.342 | 0.338 | 0.739 |
| 0.347 | 0.553 | 0.552 | 0.551 | 0.674 |
| 0.433 | 0.652 | – | 0.642 | 0.617 |
| 0.607 | – | – | 0.808 | 0.477 |
| 0.866 | 0.988 | – | 0.994 | 0.000 |

- 자유 비율은 (J/2T)/m의 함수로 크기에 무관하게 겹친다. 전환 온도는 T ~ J/L이다(5.1절).
- 액체 비율이 0.75에서 0까지 연속으로 줄어든다. (J/2T)/m ≈ 0.8–0.9에서 시료 전체가 하나의 상태로 언다. 문턱값은 아직 정확히 정하지 않았다.
- 높은 온도(y = 1)의 액체 영역은 블록 경계 변 둘이 만나는 모서리를 중심으로 한 사분원이다. 해석: 자유 경계에서는 반사 원리가 성립하므로 시료를 두 변에 대해 접어 펴면 변 2L의 Aztec diamond가 되고, 그 arctic 원의 1/4이 보인다. 넓이 비율의 예측은 π/4 = 0.785이고 계산값은 0.75다(L = 32) [논증, 곡선과의 정량 비교는 하지 않음].
- 온도를 내리면 액체 영역이 그 모서리에서 먼저 떨어지고, 반대 대각선(두 블록 경계 변의 먼 끝을 잇는 선) 쪽으로 좁아지다가 사라진다. 이 중간 모양의 식은 아직 없다.

### 5.6 모서리 스위치의 해석: 동결 온도와 연속 극한 문제 (`zpoly.py`, 2026-11-25)

**정확한 다항식 Z(y)** [수치확인]. y = 2^k에서 det(K + M)의 정수 제곱근을 구하면 2^k진 자릿수가 곧 계수 c_j(자유 플라켓이 j개인 상태 수)다. L = 4, …, 32에서 모든 계수를 얻었다. c_m = 1(바닥상태 유일)이고 c_0는 작은 소인수만 가진다(L = 16에서 2¹⁶·3²·7·11·13).

**동결 온도** [수치확인 + 추정].
- 바닥상태 위의 첫 들뜸은 자유 플라켓 두 개(서쪽 변 하나, 남쪽 변 하나)를 짝짓는 것이고, 그 수는 c_{m−2} = 2, 64, 1826, 54272, 1658722, 51637312, 1628478658, 51853213696 (L = 4, 8, …, 32)이다.
- ln c_{m−2} = κL − α ln L + b로 맞추면 연속한 세 크기에서 κ = 0.8791, 0.8801, 0.8805, 0.8808, α = 0.433, 0.451, 0.460, 0.466이다. κ → ln(1 + √2) = 0.88137, α → 1/2로 읽힌다. (5/4) ln 2 = 0.8664는 배제된다.
- 들뜸 하나의 자유에너지는 2(J/2) − T ln c_{m−2}이므로, m = L/2(자유화 가능한 플라켓 수)로 쓰면

      J / (2 T_f) = m ln(1 + √2),   T_f = J / [2 m ln(1 + √2)]

  이 아래에서 시료는 하나의 상태로 언다. 5.5절의 수치(자유 비율이 (J/2T)/m ≈ 0.87에서 1에 닿음)와 맞는다.
- 해석: (3 + 2√2)^n/√n은 중심 Delannoy 수의 증가율이다. 들뜸은 얼어붙은 상을 가로질러 서쪽 변에서 남쪽 변으로 가는 선 하나이고, 그 선이 가로·세로·대각 걸음을 갖는 격자 경로라는 뜻이다. 경로의 미시적 대응은 확인하지 않았다 [추정].

**엔트로피 함수** [수치확인]. s(f) = ln c_j / L², f = j/m.

| f | 0 | 0.25 | 0.5 | 0.75 | 0.875 | 1 |
|---|---|---|---|---|---|---|
| L = 32 | 0.0832 | 0.0817 | 0.0691 | 0.0432 | 0.0241 | 0 |
| L = 24 | 0.0819 | – | 0.0688 | – | – | 0 |

- f = 0의 극한은 (ln 2)/8 = 0.0866(변 2L인 Aztec diamond의 1/4)이다. f = 0에서 기울기 0, f = 1에서 기울기 −(1/4) ln(1 + √2) = −0.220으로 끝난다(위의 동결 온도와 같은 내용; 처음에 −0.441로 잘못 적었던 것을 고침). 유한 크기 보정이 커서 닫힌 식을 맞추지는 않았다.
- 온도 의존은 ln c_j + j ln y의 최대화, 즉 (J/2T)/m = −4 s′(f)로 정해진다(m = L/2; 처음에 −2 s′로 잘못 적었던 것을 고침).

**연속 극한 문제** [논증, 2026-11-25 저녁에 고침].
1. 높이로 쓰면 북쪽·동쪽 변은 h = X + c, h = Y + c로 고정되고, 서쪽·남쪽 변에서는 자유 플라켓 밀도 ρ가 접선 기울기(0에서 1 사이)다. 보상은 전미분이라 h(0, 0) = c − Δ 하나에만 의존한다. 이 부분은 그대로다.
2. **"자유 플라켓이 모서리에서부터 빈틈없이 찬다(계단 분포)"는 가정은 계산이 뒷받침하지 않는다** (`profile_width.py`, 5.7절). 처음 적었던 "한가운데에 얼어붙은 마름모가 있는 Aztec diamond" 그림은 이 가정 위에 있었으므로 거둔다.
3. 대신 변은 세 구간으로 나뉜다고 본다. 모서리 쪽부터 (i) ρ = 1인 얼어붙은 구간, (ii) 0 < ρ < 1인 구간, (iii) ρ = 0인 평평한 구간이다. (ii)에서는 자연 경계 조건 ∂σ/∂h_X = 0, 곧 법선 기울기 0이 성립하고 접선 기울기가 ρ다. (iii)에서는 높이가 일정하고 법선 기울기가 0이 아니다. 구간의 경계는 변분 부등식(얇은 장애물 문제)으로 정해진다.
4. 이것은 "Thermal vacancies melt arctic order"의 경계 모형과 같은 종류의 문제다. 그쪽에서는 hodograph 평면에서 혼합 경계값 문제를 풀어 가장자리 빈칸 밀도의 정확한 해를 얻었다(Screened-Dimer-Electrostatics 저장소의 `src/exact_sol.py`). 블록 경계 정사각형은 그 모형 그대로이고, 모서리 스위치는 경계 자료만 다르다(북쪽·동쪽 변이 같은 얼음상 (1, 1)에 붙는다).
5. 곡선은 아직 풀지 않았다. 4번의 방법을 이 경계 자료로 옮기는 것이 다음 일이다.

### 5.8 모서리 스위치의 해석해 (`corner_theory.py`, `corner_field.py`, `figs/corner_theory.png`, 2026-11-25)
방법은 "Thermal vacancies melt arctic order"의 hodograph 풀이다(Screened-Dimer-Electrostatics 저장소 `scripts/corner_islands/DERIVATION.md`). 그 노트의 변수와 규약을 그대로 쓰고 경계 자료만 바꿨다. 변 길이 1, S = (0, 0)이 두 블록 경계 변이 만나는 모서리, A = (1, 0), 대각선 아래 절반만 푼다.

**영역** [유도].
- Burgers 해의 꼴 v − λ(z)u = Ψ(z), ζ = (z − i)/(z + i), λ = iμ, μ = (1 − ζ²)/(1 + ζ²)는 그대로다.
- 남쪽 변의 세 구간: (i) 얼어붙은 구간 0 < u < X₁, (ii) 부분 자유 구간 X₁ < u < X₂에서 ζ = r은 실수이고 자유 밀도는 (4/π) arctan r (r: 1 → 0), (iii) 빈 구간 X₂ < u < 1에서 ζ = −is는 순허수다(접선 기울기 0, 법선 기울기 ≠ 0). X₂에서 기울기가 (0, 0)이다. 평평한 점이 변 위에 놓인다.
- 얼어붙은 경계 둘(모서리 S 쪽 안쪽 곡선, 북동쪽 바깥 곡선)은 단위원의 호 0 < φ < π/4, π/4 < φ < π/2 (ζ = e^(−iφ))다.
- 대각선은 반직선 arg ζ = −π/4 위에서 r_D < |ζ| < 1을 왕복한다. 따라서 영역은 **사분원판 {|ζ| < 1, −π/2 < arg ζ < 0}에서 그 반직선의 r_D < |ζ| < 1을 잘라 낸 것**이다. 매개변수는 r_D 하나다.
- 반평면으로 펴기: t = ζ², q = (t + 1/t)/2, p = √(q² + b²), b = (r_D⁻² − r_D²)/2, p₁ = √(1 + b²). 구간 (ii)는 p > p₁, (iii)은 p < −p₁, 두 호는 b < |p| < p₁, 대각선은 |p| < b다.

**경계 조건과 해** [유도, "특이성 없는 해"는 가정].
- 점 A의 자명한 해를 빼면 v − iμ(u − 1) = −𝔥/(ζ + ζ⁻¹)이고, 𝔥에 대한 조건은 다음과 같다. 구간 (ii)에서 Re 𝔥 = 0, 구간 (iii)과 두 호에서 Im 𝔥 = 0, 대각선에서 Im 𝔥 = −[√(1 + b² − p²) − 1]^(1/2).
- 섞인 조건은 √(p − p₁)을 떼면 풀린다.

      𝔥 = i √(p − p₁) K(p),   K(p) = C + (1/π) ∫_{−b}^{b} κ(p′) dp′/(p′ − p),   κ = [√(1 + b² − p′²) − 1]^(1/2) / √(p₁ − p′)

- 점 A에서 u = 1이려면 K(−p₁) = 0이어야 하고, 이것이 C를 정한다. 남는 매개변수는 b 하나다.
- 읽어 내는 식: 구간 (ii)에서 u = 1 + √(p − p₁) K/(1/r − r), 구간 (iii)에서 u = 1 + √(p₁ − p) K/(s + 1/s), 얼어붙은 경계는 직선족 (u − 1) sin φ + v cos φ = √(p₁ − p) K/2의 포락선이다.
- 온도: 모서리 원천의 흐름 보존에서 (J/2T)/m = x ln 2 = 2∫(½ ln|z| dv + ½ ln|w| du), 적분은 구간 (ii)의 한 점에서 대각선까지의 임의의 곡선을 따른다. 경로를 바꿔도 값이 같음을 확인했다(세 경로에서 0.3674–0.3701, b = 0.5).

**결과** [수치확인].
- 구간의 끝점이 닫힌 꼴로 읽힌다: X₁ = 1/p₁, X₂ = 1/√p₁, 곧 **X₁ = X₂²**. 네 자리까지 맞으나 유도하지는 않았다.
- b → ∞에서 사분원이 된다(바깥 곡선의 받침함수 0.0761 = 1 − sin(3π/8)).
- b → 0에서 (J/2T)/m → 0.8809 (b = 0.02). **동결 온도의 상수 ln(1 + √2) = 0.8814가 연속 해에서 나온다.** 5.6절에서는 정확한 셈에서 읽은 값이었다.
- 정확한 계산과의 비교(자유 비율):

### 5.9 모서리 스위치의 닫힌 식 (`corner_closed.py`, 2026-11-25) [유도]
5.8절의 Cauchy 적분은 닫힌 꼴로 합쳐진다. 매개변수를 a ≡ 1/p₁ (0 < a < 1, b² = 1/a² − 1)로 쓴다.

**적분을 합치는 방법.** 𝔥₀ = i(ζ − ζ⁻¹)은 5.8절의 경계 조건을 모두 만족한다. ζ − ζ⁻¹의 제곱이 2(q − 1)이라 구간 (ii)에서 순허수, 구간 (iii)과 호에서 실수이고, 대각선에서 Im 𝔥₀ = −Im(ζ + ζ⁻¹)이기 때문이다. 이것은 "모든 것이 점 S에 있다"는 자명한 해(u = v = 0)다. 일반해는 여기에 동차해 i c √(p − p₁)을 더한 것이고, 점 A에서의 조건 𝔥(−p₁) = 0이 c = √(2/p₁)을 정한다(𝔥₀(−p₁) = 2, i√(−2p₁) = −√(2p₁)).

    𝔥 = i(ζ − ζ⁻¹) + i √(2(p − p₁)/p₁)   ⇒   **Ψ(ζ) = v − iμu = −i √(2(p − p₁)/p₁) / (ζ + ζ⁻¹)**

p = √(q² + b²), q = (ζ² + ζ⁻²)/2다. 5.8절의 K(p)와 X₁, X₂, 온도에서 수치로 일치한다.

**변의 구간.** 구간 (ii)에서 u² = (p − p₁)/[p₁(q − 1)]이다. r → 1 (q → 1)에서 (p − p₁)/(q − 1) → 1/p₁이므로 X₁ = 1/p₁ = a, r → 0 (p ≈ q → ∞)에서 X₂ = 1/√p₁ = √a다. 따라서 **X₁ = X₂²**이다. q에 대해 풀면 자유 밀도가 나온다.

    ρ(u) = (4/π) arctan r,   (1/r − r)² = 4(u² − a²)/(a² − u⁴),   a ≤ u ≤ √a

자유 비율은 f = a + ∫_a^{√a} ρ du다.

**얼어붙은 경계.** 호 위에서 직선족은 u sin φ + v cos φ = √[(p₁ ∓ √(cos² 2φ + b²))/(2p₁)]이다. 제곱해 정리하면, 모서리 S에서 잰 받침함수 h(φ)(법선 (sin φ, cos φ))가

    **h √(1 − h²) = a sin φ cos φ**,   곧  h = sin χ (안쪽 곡선), cos χ (바깥 곡선),  sin 2χ = a sin 2φ

를 만족한다. a → 0이면 바깥 곡선이 h = 1(사분원), 안쪽 곡선이 점 S이고, a → 1이면 둘 다 반대 대각선 위의 선분으로 간다. 두 곡선은 한 대수 곡선의 두 가지다.

**온도.** 흐름 형식은 닫혀 있고 Ω = ½∫(ln z dv − ln w du)로 쓸 수 있다. dw/w = λ dz/z이므로 부분적분하면 Ω = ½(v ln z − u ln w) − ½∫Ψ dz/z다. 시작점을 X₂(z = i, w = −i), 끝점을 바깥 곡선이 대각선과 만나는 점(z = w = 1 + √2, u = v)으로 잡으면 경계항의 실수부가 둘 다 0이고, Ψ dz/z = i √((p − p₁)/(2p₁)) dq/(q² − 1)이므로

    **(J/2T)/m = ∫₀^∞ [g(q) − 1] dq/(q² − 1),   g(q) = √{[1 + √(1 − a² + a²q²)]/2}**

(g/(q² − 1)의 주값 적분이다.) 흐름 적분을 직접 한 값과 12자리까지 일치한다.
- a = 1이면 g = √((1 + q)/2)이고 적분은 s = √(1 + q)로 √2 ∫₁^∞ ds/(s² − 2) = ln(1 + √2)가 된다. **동결 온도 J/(2T_f) = m ln(1 + √2)의 유도다.** 이 수는 끝점의 z = cot(π/8) = 1 + √2에서 온다.
- a → 0에서 (J/2T)/m ≈ (π/4) a (1 + a²/16 + …)다.
- R = √(1 − a² + a²q²)로 바꾸면 (a/√2)∫ R dR/[(R − 1)√(R + 1)√(R² − 1 + a²)]로, 제3종 타원적분이다. 초등함수로는 a = 1에서만 닫힌다.

| 0.173 | 0.220 | 0.469 | 0.3221 | 0.3326 (L = 48) |

### 5.10 해의 유일성과 엔트로피 함수 (`corner_closed.py`, 2026-11-25)

**동차해가 하나뿐인 이유** [유도]. 5.8절의 조건을 만족하는 두 해의 차는 𝔥 = i√(p − p₁) R(p) 꼴이고, R은 실수축에서 실수인 유리함수다. 좌표 (u, v)가 시료 안에 있어 유한하다는 것만으로 R이 상수로 정해진다.
- v − iμ(u − 1) = −𝔥/(ζ + ζ⁻¹)이므로, ζ + ζ⁻¹이 0도 ∞도 아닌 모든 경계점에서 𝔥가 유한해야 한다. 따라서 R은 유한한 실수 p에서 극을 갖지 못한다. p = p₁(ζ = 1)에서도 ζ + ζ⁻¹ = 2이므로 R의 극은 𝔥를 발산시킨다.
- p = ∞ (ζ = 0, 점 X₂)에서 ζ + ζ⁻¹ ≈ √(2p)이다. R ~ pⁿ이면 우변이 pⁿ으로 커지므로 n = 0이다.
- p = −p₁ (ζ = −i, 점 A)에서는 ζ + ζ⁻¹ = 0이고 μ = ∞다. 유한하려면 𝔥(−p₁) = 0이어야 하고, 이것이 남은 상수를 정한다.

따라서 "끝점에서 발산하는 해를 더하지 않는다"는 것은 따로 둔 가정이 아니라 좌표의 유한성에서 나온다. 남는 가정은 ζ 평면의 영역 자체다(변이 세 구간으로 나뉘고 대각선이 반직선을 왕복한다는 것). 이것은 정확한 계산과의 일치가 뒷받침한다.

**자유 비율의 식** [유도]. f = a + ∫ρ du를 부분적분하고 r = tan(θ/2)로 바꾸면

    f(a) = (2√2 a/π) ∫₀^{π/2} dθ / √[sin²θ + √(sin⁴θ + 4a² cos²θ)]

이다. a = 1이면 안쪽 근호가 2 − sin²θ가 되어 f = 1이다.

**엔트로피 함수** [유도 + 수치확인]. 상태 수가 c_j이고 ln c_j + j ln y를 최대화하므로 ds/df = −(1/4)(J/2T)/m이다. f = 1에서 s = 0이므로

    s(a) = (1/4) ∫_a^1 φ(a′) f′(a′) da′,   φ ≡ (J/2T)/m (5.9절),   φ′(a) = (a/4) ∫₀^∞ dq/(g R),  R = √(1 − a² + a²q²)

| a | f | (J/2T)/m | s |
|---|---|---|---|
| 0.001 | 0.0032 | 0.0008 | 0.086643 |
| 0.2 | 0.2989 | 0.1575 | 0.08139 |
| 0.4 | 0.5110 | 0.3175 | 0.06896 |
| 0.6 | 0.6917 | 0.4834 | 0.05098 |
| 0.8 | 0.8528 | 0.6615 | 0.02804 |
| 0.95 | 0.9643 | 0.8150 | 0.00755 |

- **a → 0에서 s → 0.086643이고, (ln 2)/8 = 0.0866434다.** 변 2L인 Aztec diamond의 1/4이 갖는 엔트로피가, 동결 쪽에서부터 온도 식을 적분한 값으로 재현된다. 온도 식과 자유 비율 식 전체를 한 번에 시험하는 독립 검증이다(이 값은 풀이에 넣지 않았다).
- 정확한 셈과의 비교: f = 0.5에서 0.0697(해석) 대 0.0691(L = 32), f = 0.75에서 0.0435 대 0.0432.
- φ가 제3종 타원적분이라 s를 초등함수나 적분 하나로 줄이지는 못했다. 위의 이중 적분이 현재의 꼴이다. ∫₀¹ φ f′ da = (ln 2)/2라는 항등식의 해석적 증명도 하지 않았다.

### 5.11 유효 모형의 검증: 꼭짓점 모형의 정확한 상태 밀도 (`vertex_dos.py`, `vertex_thermo.py`, 2026-11-26) [수치확인]
유한 온도의 경계 단량체 모형(5.1절)은 지금까지 눈금 논증이었다. 모서리 스위치 시료에서 원래의 꼭짓점 모형(모든 스핀 상태, `gen_ilp.py`의 꼭짓점 에너지)의 상태 밀도 g(E)를 격자점 단위 전달행렬로 정확히 구해 비교했다. 몬테카를로가 아니라 전수 계산이다(L = 20에서 섬 693개, 열린 섬 최대 18개).

**바닥상태와 첫 들뜸은 맞는다.**
- L = 4, 8, 12, 16, 20 모두에서 바닥 에너지가 유효 모형의 값과 같고 겹침수는 2(전체 스핀 뒤집기)다. 바닥상태는 유일하다.
- 에너지 J 위의 상태 수는 유효 모형의 c_{m−2}에 거의 일정한 수를 곱한 것이다.

| g(E_gs + J)/g(E_gs) | 35 | 989 | 28615 | 859865 |

**해석** [논증, 미확정]. 얼어붙은 영역 안의 벌크 들뜸은 끈 모양의 결함으로, 비용이 2J이고 엔트로피가 끈 길이에 비례한다(가장자리 쌍 결함과 같은 증가율 κ = ln(1 + √2)를 가정). 볼츠만 인수는 exp(−2φL + (κ/2)ℓ₁), φ = (J/2T)/m, ℓ₁ ≤ 2L이므로 φ > κ/2 ≈ 0.44이면 어떤 길이에서도 억제된다. 그보다 높은 온도에서는 얼어붙은 영역이 충분히 길면 끈 결함이 늘어날 수 있고, 그러면 얼어붙은 영역이 유효 모형의 예측보다 더 녹는다. 이것은 동반 논문의 "전체 모형 대 경계 모형" 문제와 같은 종류다. 이 문턱은 추정이고 확인하지 않았다.

**결론.**
1. 바닥상태의 유일성, 동결 온도의 상수, 동결 근처((J/2T)/m ≳ 0.8)의 온도 의존은 꼭짓점 모형에서 확인된다. 단 w ≈ 4의 유한 크기 보정을 넣어야 한다.
2. 그보다 높은 온도에서 5.8–5.9절의 해석해가 꼭짓점 모형의 극한인지는 아직 열려 있다. L ≤ 20에서는 들뜸 에너지가 해석해의 약 두 배다.
3. 다음 일: 벌크 끈 결함을 넣은 모형("전체 모형")의 정식화, 또는 더 큰 크기(L = 24–32, 고정 β 전달행렬이나 몬테카를로)에서 차이의 추세 확인. 액체 지도 자체의 비교도 하지 않았다.

### 5.12 빠진 상태의 정체: 모든 변의 반쪽 dimer 자리 (`vertex_enum.py`, `owner_fit.py`, `corrected_model.py`, 2026-11-26) [수치확인 + 논증]
5.11절의 추정(벌크 끈 결함)은 틀렸다. 빠진 상태는 벌크가 아니라 가장자리에 있었다.

**첫 들뜸의 완전한 열거** (L = 8: 1978개, L = 12: 57230개 상태). 모든 상태에서 바닥상태에 없던 불행한 z3 꼭짓점이 경계점에 정확히 두 개 생긴다(끈의 두 끝). 끝점의 종류:
- F: 자유화 가능한 플라켓과 이웃이 공유하는 경계점. 기존 유효 모형의 "자유 플라켓을 다시 짝짓기"다. **F–F 끈의 수는 유효 모형과 정확히 같다** (64 = 64, 1826 = 1826).
- H: 그 밖의 경계 z3 점. 불행해지면 한 플라켓만 덮는 "반쪽 dimer"가 되고 에너지 J가 든다(dimer는 J를 두 플라켓이 나눈다). 끝점 하나의 비용은 F와 같은 J/2다. H 자리는 **네 변 모두에** 있다. 블록 관통 변(북·동)에도, 블록 경계 변(서·남)의 자유화 불가능한 플라켓에도 있다.

**H 자리의 무게** (끝점별 개수를 맞춰 정함, L = 8과 12에서 같은 규칙):
- 플라켓 하나에만 닿는 점, 원래 격자에서 z = 3: 무게 2.
- 플라켓 하나에만 닿는 점, 원래 격자에서 z = 4 (모서리): 무게 1.
- 서로 이웃하지 않은 두 플라켓에 닿는 점: 자유화 불가능한 쪽 플라켓마다 무게 1.

**고친 유효 모형.** 바깥 면의 단량체 자리가 자유화 가능한 플라켓(무게 1, 에너지 0)과 H 자리를 가진 플라켓(무게 n_c t, t = e^{−J/T})이고 dimer가 t를 갖는 Pfaffian 모형이다. 단량체가 모두 바깥 면에 있으므로 정확히 풀린다. 플라켓별 무게가 다른 경우도 L = 4, 8에서 전수 계산과 일치한다(`brute_w.py`).

|---|---|---|---|
| E_gs + J | 989 / 988 | 28615 / 28614 | 859865 / 859864 |
| E_gs + 2J | 1.264 (비) | 1.188 | 1.172 |
| E_gs + 3J | 2.44 | 1.55 | 1.45 |

- 첫 들뜸은 상태 하나(모서리의 끝점 하나짜리 상태)만 빼고 정확히 맞는다. 둘째 준위부터의 남은 차이(벌크 결함 등)는 크기와 함께 줄어든다.
- 들뜸 에너지 ⟨E − E_gs⟩/(mJ/2):

  차이는 0.433에서 0.186, 0.057, 0.034, 0.026 (L = 8–20)으로 줄어든다. 5.11절에서 "w ≈ 4의 국소 보정"이라고 부른 것은 대부분 H 끝점이었다.

**색과 경계 에너지** [논증]. 서쪽 변의 자유 플라켓은 흰색, 서쪽 변의 H 플라켓은 검은색이다(남쪽은 반대). 북쪽의 H는 검은색, 동쪽의 H는 흰색이다. 서쪽 변의 에너지는 −(J/2)(흰 단량체 수) + (J/2)(검은 단량체 수)로 단량체의 알짜 색에 비례하고, 이것은 변을 따른 높이 차다. 네 변을 모두 더하면 변 안쪽은 사라지고 모서리 높이만 남는다.

    경계 에너지 ∝ h(북동) − h(남서)

동반 논문의 범함수 (x ln 2/4)[H(S) + H(N) − H(W) − H(E)]와 같은 꼴이다. 그쪽은 네 모서리가 번갈아 원천과 흡수원이고, 모서리 스위치는 대각선 한 쌍(남서 원천, 북동 흡수원)만 있다. 변에서는 단량체 밀도가 허용 범위 안이면 자연 경계 조건이 성립한다. 허용 범위는 변마다 다르다(서·남은 양쪽 색, 북·동은 한쪽 색).

**높은 온도에서 시료 전체가 액체다** (L = 32, 고친 모형):

| 액체 비율 | 0.998 | 0.991 | 0.926 | 0.862 | 0.699 | 0.562 |

원래 모형은 높은 온도에서 사분원(0.75)이었다. 모서리 원천이 사라지면 자연 경계 조건만 남아 얼음이 없기 때문이다.

**결과의 정리.**
1. 그대로인 것: T = 0의 모든 결과, 스위치 시료의 조건과 바닥상태의 유일성, 동결 온도의 상수 ln(1 + √2) (첫 들뜸이 정확히 맞고 증가율이 같다).
2. 바뀌는 것: 5.5–5.10절의 hodograph 해는 원래 모형(북·동 변 고정)의 정확한 해로는 맞지만, 꼭짓점 모형의 눈금 극한은 아니다. 물리적인 극한은 "남서·북동 두 모서리에 원천이 있는 빈칸 문제"이고 아직 풀지 않았다. 스위치는 오히려 강해진다(완전한 액체 ↔ 완전한 얼음).
3. 블록 관통 변도 유한 온도에서는 H 자리 때문에 온도에 의존한다. 5.4절의 "O 넷은 온도 무관"은 틀렸다. 네 변이 모두 블록 관통인 Aztec 정사각형은 동반 논문의 경계 모형 그 자체일 가능성이 크다(확인하지 않음).
4. 벌크 결함은 둘째 준위부터 있고 상대 무게가 크기와 함께 줄어든다. 눈금 극한에서 사라지는지는 확인하지 않았다.

### 5.13 고친 모서리 스위치의 눈금 해 (`corner2_theory.py`, `fig_corner2.py`, `figs/corner2_theory.png`, 2026-11-26) [유도 + 수치확인]
5.12절의 고친 모형(네 변 모두 자연 경계 조건, 경계 에너지 ∝ h(북동) − h(남서))을 같은 hodograph 방법으로 풀었다.

**영역은 5.8절과 같다.** 사분원판 {|ζ| < 1, −π/2 < arg ζ < 0}에서 반직선 arg ζ = −π/4의 r_D < |ζ| < 1을 잘라 낸 것이다. 각 부분의 뜻이 바뀐다.
- 실수축 0 < r < 1: 남쪽 변의 자연 경계 구간(남서 얼음 모자의 끝 X₁에서 남동 모서리까지). 접선 기울기 (4/π) arctan r.
- 허수축: **동쪽 변**의 자연 경계 구간(u = 1). 5.8절에서는 남쪽 변의 빈 구간이었다.
- ζ = 0: **남동 모서리**(평평한 점). 5.8절에서는 변 위의 X₂였다.
- 호 0 < φ < π/4: 남서 얼음 모자의 경계, 호 π/4 < φ < π/2: 북동 얼음 모자의 경계.
- 잘린 선분의 두 쪽: 대각선의 남서 절반과 북동 절반. 끝(p = 0)이 시료의 중심이다.

**조건과 해.** v − iμ(u − 1) = −𝔥/(ζ + ζ⁻¹)로 쓰면 실수축과 허수축 모두에서 Re 𝔥 = 0, 호에서 Im 𝔥 = 0, 대각선에서 Im 𝔥 = −[√(p₁² − p²) − 1]^{1/2}이다(p₁² = 1 + b²). 인수 √(p² − p₁²)를 떼면

    𝔥 = i √(p² − p₁²) K(p),   K(p) = (1/π) ∫_{−b}^{b} κ(p′) dp′/(p′ − p),   κ = [√(p₁² − p′²) − 1]^{1/2} / √(p₁² − p′²)

- 반대각선에 대한 반사와 h → −h를 합친 대칭에서 K가 홀함수여야 하므로 **더할 상수가 없다**. 남은 매개변수는 b 하나다. 이 대칭에서 중심 (½, ½)과 두 모자의 대칭이 자동으로 나온다(수치로 확인: b = 2에서 모자의 끝점 (0.587, 0) ↔ (1, 0.413), (0.213, 0.213) ↔ (0.787, 0.787)).
- 얼어붙은 경계: 직선족 (u − 1) sin φ + v cos φ = √(p₁² − p²) K(p)/2의 포락선, q = cos 2φ.
- 온도: 남서 원천의 흐름 절반이 남동 모서리(ζ = 0)에서 대각선의 남서 절반까지의 경로를 지난다. (J/2T)/m = 2[½∫ln|z| dv − ½∫ln|w| du].
- b → ∞에서 모자가 사라지고(시료 전체가 액체), b → 0에서 두 모자가 두 삼각형을 채운다. 이때 (J/2T)/m → 0.87–0.88 (수치, ln(1 + √2) = 0.881).

**정확한 계산과의 비교** (고친 Pfaffian 모형, 액체 = P_max < 0.9인 칸의 비율):

| (J/2T)/m | 눈금 해 | L = 32 | 48 | 64 |
|---|---|---|---|---|
| 0.26 | 0.940 | 0.956 | 0.951 | 0.945 |
| 0.433 | 0.820 | 0.862 | 0.841 | 0.834 |
| 0.6 | 0.645 | 0.699 | 0.668 | 0.650 |
| 0.7 | 0.50 | 0.562 | 0.519 | 0.500 |
| 0.8 | 0.312 | – | 0.315 | – |

정확한 값이 크기와 함께 눈금 해로 다가가고, 얼어붙은 경계 두 곡선이 L = 48의 지도와 겹친다.

**남은 것.** K의 닫힌 꼴(5.9절처럼 특수해를 찾으면 초등함수가 될 수도 있다), X₁(b)와 온도의 닫힌 식, b → 0 극한의 해석적 계산(동결 상수), 큰 b에서 흐름 적분의 수치 안정성(지금은 b ≲ 40까지). 영역 구조는 여전히 가정이다.

### 5.14 고친 모서리 스위치: 동결 상수와 온도 식 (`corner2_theory.py`의 `field_closed`, `X1`, 2026-11-26) [유도 + 수치확인]

**K는 초등함수로 닫히지 않는다** [논증]. 5.9절에서 닫힌 꼴이 나온 것은 자명한 특수해(모든 것이 점 S에 있는 해)가 대각선 조건을 만족했기 때문이다. 이번 문제에서 점 해 Ψ = c₁ + c₂λ (점 (−c₂, c₁))는 남쪽 변(v = 0), 동쪽 변(u = 1), 대각선(u = v)을 동시에 만족할 수 없다((0, 0)은 동쪽 변, (1, 0)은 대각선, (1, 1)은 남쪽 변을 어긴다). 따라서 Cauchy 적분이 그대로 남는다. p′ = p₁ sin θ로 바꾸면

    K(p) = (1/π) ∫_{−θ_b}^{θ_b} √(p₁ cos θ − 1) dθ / (p₁ sin θ − p),   cos θ_b = 1/p₁

로 타원적분 꼴이다. b → 0에서는 κ ≈ √((b² − p′²)/2)가 반원 밀도라서 K ≈ [√(p² − b²) − p]/√2로 닫힌다.

**온도는 적분 하나다.** 5.9절의 부분적분 Ω = ½(v ln z − u ln w) − ½∫Ψ dz/z를 남동 모서리(ζ = 0, z = i, w = −i)에서 남서 모자와 대각선이 만나는 점(ζ = e^{−iπ/4}, z = w = cot(π/8) = 1 + √2, u = v)까지, 남쪽 변을 따라간 뒤 남서 모자의 경계를 따라 적분한다. 경계항의 실수부는 두 끝에서 0이다. Ψ = −iμ − 𝔥/(ζ + ζ⁻¹)에서 −iμ 부분은 ∫λ dz/z = ln w로 정확히 적분되어 ln(1 + √2)를 준다. 나머지는 𝔥 dz/[z(ζ + ζ⁻¹)] = −𝔥 dq/[2(q² − 1)]로, 남쪽 변에서는 순허수라 기여가 없고 모자 경계에서만 남는다.

    (J/2T)/m = ln(1 + √2) + ½ ∫₀¹ K(√(q² + b²)) dq/√(1 − q²)

- K < 0이므로 둘째 항은 음수이고, b → 0에서 0으로 간다. 따라서 **동결 온도 J/(2T_f) = m ln(1 + √2)가 고친 모형에서도 유도된다.** 상수는 이번에도 모자와 대각선이 만나는 점의 z = cot(π/8)에서 온다.
- 경로를 따라 흐름을 직접 적분한 값과 b ≤ 2에서 소수 넷째 자리까지 같다(0.6417 대 0.6417, b = 1). 큰 b에서 불안정하던 경로 적분과 달리 이 식은 b = 200까지 안정하다.

**얼음 모자가 변과 만나는 점** [유도]. r → 1에서 u → 1 + K(p₁)이므로 X₁ = 1 + K(p₁)이다. 포락선으로 구한 끝점과 다섯 자리까지 같다.

| b | (J/2T)/m | X₁ |
|---|---|---|
| 0.05 | 0.8792 | 0.9991 |
| 0.3 | 0.8343 | 0.9701 |
| 1 | 0.6417 | 0.7881 |
| 2.315 | 0.4320 | 0.5449 |
| 10 | 0.1958 | 0.2492 |
| 200 | 0.0424 | 0.0540 |

- 높은 온도(b → ∞)에서 (J/2T)/m ≈ 0.60/√b, X₁ ≈ 0.76/√b로, X₁ ≈ (4/π)(J/2T)/m에 가깝다(수치에서 읽음, b = 40–200에서 1.27). 모자의 크기가 온도의 역수에 비례하고, 액체 비율은 1 − O((J/2T)²/m²)로 1에 다가간다.

**정리.** 고친 모서리 스위치는 다음으로 닫힌다: 영역(5.13절), 해 𝔥 = i√(p² − p₁²)K(p) (K는 대각선 자료의 Cauchy 적분, 상수 없음), 얼음 경계(직선족의 포락선), X₁ = 1 + K(p₁), 온도 적분, 동결 상수 ln(1 + √2). 초등함수로 닫히지 않는 것은 K 하나이고, 나머지는 모두 K를 통한 1차원 적분이다.

### 5.15 블록 관통 Aztec 정사각형 = 빈칸 논문의 경계 모형 (`aztecO.py`, `aztecO_float.py`, 2026-11-26) [수치확인 + 논증]
네 변이 모두 블록 관통(술 마감)인 정사각형 X, Y ∈ [1, L + 1]은 T = 0에서 차수 N = L/2 − 1인 Aztec diamond다(바닥상태 수 2^{N(N+1)/2}). 유한 온도에서는 반쪽 dimer 자리 때문에 온도에 의존한다(5.4절의 "온도 무관"은 틀렸다).

**자리의 구조.** 자유화 가능한 플라켓은 없고, 반쪽 dimer 자리는 네 변 모두에서 **경계 칸 하나 걸러 하나**, 무게 2다(L = 8, 12, 16에서 2N개). 색은 그 변의 경계 칸 색과 같다(서·동 흰색, 남·북 검은색). 짝지어진 dimer 하나를 단량체 두 개로 바꾸는 비용이 J이므로 단량체 하나의 퓨개시티는 2e^{−J/2T}다.

**꼭짓점 모형과 일치.** 첫 들뜸의 수가 정확히 같다: 768 / 768 (N = 3), 1966080 / 1966080 (N = 5), 67645734912 / 67645734912 (N = 7). 둘째 준위의 비는 2.54, 1.30, 1.13으로 1에 다가간다.

**빈칸 논문의 모형과의 대응.** 그쪽 경계 모형은 Aztec diamond의 4N개 경계 칸 모두에 퓨개시티 z = 2^{−xN/2}인 단량체를 허용한다. 대응은

    2 e^{−J/2T} = 2^{−xN/2},   곧  J/T = (xN + 2) ln 2

이다. x = 1이 vorticity 원고의 T_on = J/[(N + 2) ln 2]와 정확히 같다.
- 자리가 경계 칸의 절반뿐이지만, 그쪽 해에서 빈칸 밀도는 ½ − (2/π) arctan r < ½이라 절반을 넘지 않는다. 눈금 극한의 경계 항은 알짜 단량체 수(높이)에만 의존하므로 같은 극한이 기대된다 [논증].
- σ_N(x) = 1 − ⟨단량체 수⟩/(2N)를 고친 모형으로 N = 7–47에서 계산했다.

**뜻.** 네 변을 블록 관통으로 자르고 섬을 남겨 마감한 Shakti 정사각형은 "Thermal vacancies melt arctic order"의 경계 모형을 물리적으로 구현한다. 온도 눈금은 x = (J/T − 2 ln 2)/(N ln 2)이고, arctic 원이 녹기 시작하는 x = 1이 T_on이다. 남은 것: 둘째 준위부터의 벌크 결함이 눈금 극한에서 사라지는지(전체 모형 대 경계 모형과 같은 질문), 유한 N 보정의 형태.
